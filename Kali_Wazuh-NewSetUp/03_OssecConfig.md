နည်းပညာနယ်ပယ်မှာ အတော်လေး စိတ်ဝင်စားစရာကောင်းပြီး ဆွေးနွေးစရာဖြစ်နေတဲ့ အကြောင်းအရာတစ်ခုပါ။ အထူးသဖြင့် လုပ်ငန်းခွင်သုံးစက်တွေမှာ User ရဲ့ ခွင့်ပြုချက်မပါဘဲ Storage အမြောက်အမြားကို ယူသုံးနေတာဟာ စွမ်းဆောင်ရည်ပိုင်းရော၊ လုံခြုံရေးပိုင်းပါ စိုးရိမ်စရာဖြစ်တယ်ပါတယ်။

အဲဒီ Folder ထဲက ဖိုင်တွေနဲ့ ပတ်သက်ပြီး နည်းပညာရှုထောင့်ကနေ ရှင်းပြပေးပါမယ်။

### ၁။ `optimization_guide_model_store` ဆိုတာ ဘာလဲ?

ဒီ Folder ဟာ Google Chrome ရဲ့ **"Optimization Guide"** ဆိုတဲ့ Feature အတွက် ဖြစ်ပါတယ်။ Chrome ဟာ User ရဲ့ Browsing အတွေ့အကြုံ မြန်ဆန်စေဖို့၊ စာမျက်နှာတွေကို ပိုမိုကောင်းမွန်စွာ Render လုပ်ဖို့နဲ့ AI အခြေခံတဲ့ အင်္ဂါရပ်တွေ (ဥပမာ- စာသားအနှစ်ချုပ်ခြင်း၊ စာလုံးပေါင်းစစ်ဆေးခြင်း စတဲ့ Gemini Nano စွမ်းဆောင်ရည်များ) ကို Local (Device ပေါ်မှာတင်) လုပ်ဆောင်နိုင်ဖို့အတွက် အဲဒီ Model ဖိုင်တွေကို ဒေါင်းလုဒ်ဆွဲထားခြင်း ဖြစ်ပါတယ်။

### ၂။ ဘာလို့ ခွင့်ပြုချက်မယူတာလဲ?

အမှန်တော့ Google Chrome ရဲ့ Settings (Privacy and Security) ထဲမှာ "Help improve Chrome's features and performance" ဆိုတဲ့ option ပါဝင်ပါတယ်။ အဲဒါကို Turn on လုပ်ထားရင် သူက နောက်ကွယ်ကနေ အဲဒီ Model တွေကို ဒေါင်းလုဒ်ဆွဲတတ်ပါတယ်။ အဓိကရည်ရွယ်ချက်ကတော့ Cloud Server ဆီ အချက်အလက်တွေ အမြဲမပို့ရအောင် **"Privacy-First"** (Device ပေါ်မှာတင် စစ်ဆေးပေးခြင်း) ဖြစ်ဖို့ ရည်ရွယ်တာပါ။ ဒါပေမဲ့ ၄ GB နီးပါးလောက်အထိ ယူသုံးတာကတော့ User အတွက် တကယ်ကို များလွန်းပါတယ်။

### ၃။ Wazuh နဲ့ ဘယ်လို စောင့်ကြည့်မလဲ?

သင် Wazuh Agent ထည့်ထားပြီးသားဖြစ်တဲ့အတွက် အဲဒီ Folder ထဲမှာ **ဖိုင်အသစ်တွေ ထပ်ရောက်လာတာ** သို့မဟုတ် **ဖိုင်တွေ ပြောင်းလဲသွားတာ** ကို Wazuh ရဲ့ FIM (File Integrity Monitoring) နဲ့ စောင့်ကြည့်လို့ရပါတယ်။

**Wazuh Agent (Windows 11) ရဲ့ `ossec.conf` မှာ အောက်ပါအတိုင်း ထည့်သွင်းပေးပါ:**

```xml
<syscheck>
  <directories check_all="yes" realtime="yes">C:\Users\<userName>\AppData\Local\Google\Chrome\User Data\optimization_guide_model_store</directories>
</syscheck>
```

_(မှတ်ချက် - `<userName>` နေရာမှာ သင့် PC ရဲ့ User Name ကို အမှန်ထည့်ပေးပါ)_

ဒီလိုထည့်ထားလိုက်ရင် အဲဒီ Folder ထဲကို Chrome က ဖိုင်အသစ်ထပ်ထည့်တာ၊ ရှိပြီးသားဖိုင်တွေကို ပြောင်းလဲတာ လုပ်လိုက်တာနဲ့ Wazuh က Alert ချက်ချင်းပေးပါလိမ့်မယ်။

### ၄။ ဘယ်လို ဖြေရှင်းမလဲ?

စွမ်းဆောင်ရည်ပိုင်းအတွက် စိုးရိမ်တယ်ဆိုရင် အခုလို လုပ်လို့ရပါတယ် -

1. **Chrome Settings:** `chrome://settings/performance` သို့မဟုတ် `chrome://settings/cookies` ထဲကိုသွားပြီး အသုံးမလိုတဲ့ AI feature တွေကို ပိတ်ထားကြည့်ပါ။
2. **Delete:** အဲဒီ Folder ထဲက ဖိုင်တွေကို ဖျက်လို့ရပါတယ်။ ဒါပေမဲ့ Chrome က အလိုအလျောက် ပြန်ဒေါင်းလုဒ်ဆွဲတတ်တာမျိုး ရှိနိုင်ပါတယ်။
3. **Group Policy:** လုပ်ငန်းခွင်သုံး စက်တွေဖြစ်ရင် IT Admin ကနေတစ်ဆင့် Chrome ရဲ့ "Optimization Guide" ကို Disable လုပ်တဲ့ Policy ကို ချမှတ်ခြင်းအားဖြင့် ဒီပြဿနာကို ဖြေရှင်းနိုင်ပါတယ်။

**နည်းပညာအရ ပြောရရင်:** ကုမ္ပဏီကြီးတွေဟာ AI ပြိုင်ပွဲမှာ အသာစီးရဖို့အတွက် User ရဲ့ Device Resources ကို အလွန်အကျွံသုံးစွဲလာတာက ဝေဖန်စရာဖြစ်ပါတယ်။ Wazuh နဲ့ စောင့်ကြည့်ထားခြင်းအားဖြင့် သင့်စက်ရဲ့ အခြေအနေကို အမြဲသိရှိနိုင်ပြီး Security Control ပိုကောင်းလာမှာပါ။

### 5။ Wazuh Agent ကို Restart ချခြင်း

Config ဖိုင်ကို Save လုပ်ပြီးသွားရင် အပြောင်းအလဲတွေ အသက်ဝင်ဖို့အတွက် Wazuh Service ကို PowerShell မှာ ဒီလို Restart ချပေးပါ -

```PowerShell
Restart-Service -Name Wazuh
```
